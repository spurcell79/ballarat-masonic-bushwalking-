# Ballarat Masonic Bushwalking Club Prototype

A polished static prototype for the inaugural website.

## View locally
From this directory:

```bash
python3 -m http.server 4173
```

Then open: http://127.0.0.1:4173

## Included
- Mobile-first homepage
- First walk feature: Sat 9 May, 10:00 AM, Slatey Creek Campground No. 1
- About section
- Upcoming walk detail card
- FAQ & safety notes
- Join/enquiry prototype form
- Visual direction: Victorian bushland, eucalyptus, sandstone, subtle brass, understated masonic geometry
